# 린스크 자막 스튜디오

9:16 릴스·쇼츠용 자막/스티커 편집 웹앱. 파일 하나(`index.html`)로 동작하며, 사진·영상·음악은 서버로 전송되지 않고 브라우저 안에서만 처리됩니다.

## 여는 방법

- `index.html`을 브라우저로 열면 바로 실행됩니다.
- 로컬 서버로 열려면 이 폴더에서:

```bash
python3 -m http.server 8765
# 브라우저에서 http://localhost:8765/index.html
```

## 기본 사용 흐름

1. **+ 사진·영상**으로 사진/영상을 추가하거나, 처음 열었을 때 뜨는 린스크북스 샘플 컷으로 바로 테스트합니다.
2. 미리보기 캔버스에서 **자막·스티커를 끌어** 위치를 옮깁니다. 선택하면 점선 박스와 ✕(삭제)가 나타납니다.
3. **타임라인**에서 재생 위치를 옮기고, **+ 자막 추가**로 현재 위치에 자막을 넣습니다.
4. 아래 5개 탭에서 자막·스티커·폰트·디자인·미디어/BGM을 조정합니다.
5. **영상 저장**을 누르면 처음부터 끝까지 다시 재생하면서 MP4(또는 WebM) 파일을 만들어 내려받습니다. 저장 중에는 화면을 닫지 마세요.

## 기능

- **재생/저장**: 재생·일시정지, `현재초 / 전체초`, `영상 저장` (Canvas `captureStream()` + `MediaRecorder`, BGM·영상 소리 포함)
- **컷 편집**: 젤앞 / 앞 / 뒤 / 젤뒤 / 분할 / 프리즈 / 색감(기본·따뜻함·필름·흑백) / 음량(100·70·40·0%) / 삭제
- **타임라인**: 컷 트랙(썸네일·길이 비례), 자막 트랙(겹치면 자동 2줄 배치), 드래그로 재생 위치·자막 구간 이동
- **구간·자막**: 자막 목록, 텍스트, 시작/끝 초, 글자색 7종, 배경 프리셋 7종
- **스티커**: 라라(파랑 몸통·오렌지 귀), 꽃, 별, 스마일, LINSK 배지, 하트, 반짝, 새싹 — 크기(px)·회전 슬라이더, 복제
- **폰트**: 고딕(Noto Sans KR) / 명조(Nanum Myeongjo) / 손글씨(Nanum Pen Script) / 굵은고딕(Black Han Sans), 크기, 외곽선(두께·색), 그림자(번짐)
- **디자인**: 9:16 · 4:5 · 1:1 비율, 여백 스타일(꽉차게/기본/넓게), `@namjihye2026` 워터마크 ON/OFF 및 문구 수정
- **미디어·BGM**: 사진·영상 추가/빼기, 로컬 오디오(BGM) 추가와 음량
- **자동 저장**: 자막·스티커·폰트·디자인 설정을 `localStorage`에 저장하고 다시 열 때 복원

## 알아둘 점

- 저장 형식은 브라우저가 지원하는 것에 맞춰 자동 선택됩니다(Chrome·Edge는 MP4, 미지원 브라우저는 WebM). Chrome 데스크톱에서 만든 MP4는 VP9 코덱일 수 있어, 일부 편집 앱이나 인스타그램 업로드에서 인식이 안 되면 iPhone Safari에서 다시 저장하는 편이 확실합니다.
- `MediaRecorder`로 만든 파일은 재생은 되지만 일부 플레이어에서 탐색(스크러빙)이 제한될 수 있습니다.
- 영상 저장 중에는 다른 탭으로 전환하지 말고, 끝날 때까지(전체 길이만큼) 기다려 주세요.
- 큰 영상 여러 개를 넣으면 브라우저 메모리를 많이 씁니다. 릴스용은 10초 이내 컷 여러 개로 나누는 편이 안정적입니다.

# 🔥 인기글 후킹 & 제목 생성기 (`/hook/`)

키워드 하나만 넣으면 네이버 블로그 상위노출 공식대로 제목 10개가 나오고, 쓴 글을 붙여 넣으면 10가지를 실시간 채점합니다.

- **제목 10개**: 키워드를 맨 앞에 두고 후킹 문구를 뒤에 붙인 제목 10개 (5개 트랙 · 다른 각도로 다시 뽑기) · 1클릭 복사
- **본문 점검**: 키워드 횟수(띄어쓰기 무관) · 초반/중반/후반 배치(2·3·2) · 후킹 단어 · 해시태그 1개 · 스티커·이미지 4~5장·동영상 체크
- **배치 예시 7문장**: 초반 2 · 중반 3 · 후반 2에 키워드를 넣은 문장 예시 복사
- **(선택) AI 훅**: 비서실 앱과 같은 Gemini/Claude 키를 넣으면 스레드·카드뉴스·릴스 훅을 추가 생성 (키 없이도 1~5번 기능 전부 동작)
- 입력한 키워드·제목·본문은 `localStorage`에만 저장됩니다.

# 📊 LINSK 견적 계산기 (`/quote/`)

- **PCO 탭**: 행사 유형·인원·일수·장소·통역·국내외 연사·홍보물·촬영·식음·운영인력 → 항목별 내역, 1인당, 부가세 포함 총액
- **출판 탭**: 스탠다드 POD 150만 / 프리미엄 통합 200만 / 전자책 단독 / KDP 영문판 / ISBN·교보POD 패키지 + 추가 옵션, 계약금 50%
- **내보내기**: 견적서 요약 복사 · `info@linsk.co.kr` 메일 초안 · 채널톡 상담 · A4 견적서 인쇄(PDF)
- **단가표 직접 수정**: 모든 단가는 부산 기준 참고값이며, 앱 안에서 직접 고쳐 이 브라우저에 저장할 수 있습니다.
