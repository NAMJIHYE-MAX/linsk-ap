## 국문·영문 전환

같은 요소에 `data-ko` / `data-en` 속성으로 두 언어 문장을 함께 넣고, 우상단 KO·EN 버튼이
`innerHTML`을 바꿔 끼웁니다. 선택한 언어는 브라우저에 저장(`localStorage: hyedo_lang`)됩니다.

```html
<h2 data-ko="연구소 소개" data-en="About the Institute">연구소 소개</h2>
```

입력창 안내문은 `data-ph-ko` / `data-ph-en`, 문서 제목은 스크립트에서 언어별로 바꿉니다.
새 문장을 넣을 때 `data-ko`만 넣으면 영문 전환 시 이전 문장이 남으므로 반드시 두 속성을 함께 넣습니다.

## 확인 후 업데이트할 항목

페이지에서 `[확인 후 업데이트 예정]` / `[To be updated]` 로 표시된 곳입니다.

1. About 개요표의 **소재지**
2. Contact의 **이메일·전화·주소·사업자등록번호**
3. Footer의 **사업자등록번호·주소**
4. People의 **김동욱 연구원 학력·경력 프로필**
5. Contact 문의 양식 — 현재 시안이므로 실제 전송되지 않습니다(제출 시 안내 문구만 표시).
   정식 오픈 시 폼 백엔드(예: Formspree, Google Forms)나 메일 링크로 연결해야 합니다.

상단 DRAFT 띠는 시안임을 알리는 표시입니다. 정식 오픈 때 `index.html`의 `<div class="draftbar">` 블록을 지우면 됩니다.

검색 노출은 시안 단계라 막아 두었습니다. `<head>`의 `<meta name="robots" content="noindex, nofollow">` 한 줄을 지우면 검색엔진에 노출됩니다.

## 표기 원칙 (수정 시 지켜 주세요)

- 연구소는 혜도씨앤씨의 **사내 연구조직**이며, 정부 공인 기업부설연구소가 아닙니다. 이 문구는 About과 Footer에 유지합니다.
- 논문·저서는 **연구소장 개인 연구실적(설립 이전)** 과 **연구소 설립 이후 성과(2026.12~)** 로 나누어 표기합니다. 설립 이전 실적을 연구소 성과로 옮겨 적지 않습니다.
- 확인되지 않은 협력기관·연구실적·법인정보를 채워 넣지 않습니다. 확정된 뒤에 해당 자리에만 기입합니다.
- 2027년 과제는 "착수 예정"으로 표시하며, 수주·협약이 끝나기 전에는 "진행 중"으로 바꾸지 않습니다.
